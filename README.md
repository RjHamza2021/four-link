# Network Connect Hub

PROJECT: 4NDS NETWORK — UK WEBSITE REDESIGN

Create a completely new, premium, highly interactive website experience for:

4NDS Network

https://4nds.com/

The new site is intended for the UK market while preserving the established 4NDS brand identity.

IMPORTANT:

This is NOT a conventional corporate agency website.

Do NOT create a generic SaaS landing page.

Do NOT create a standard WordPress/Elementor agency design.

Do NOT simply restyle the existing website.

The website should feel like a distinctive digital experience.

CORE CREATIVE DIRECTION:

NEO-BRUTALISM / NEUBRUTALISM + DIGITAL NETWORK SYSTEM + EDITORIAL STORYTELLING + HIGH-END MOTION DESIGN.

Primary visual references:

- https://growthlab.com.co/en

- https://gumroad.com/

- Neo-brutalist digital agency websites

- Experimental editorial web design

- Interactive digital product websites

Use these websites for inspiration only.

DO NOT copy layouts, wording, illustrations, assets, animations, or branding.

==================================================

2. DESIGN PHILOSOPHY

==================================================

The design should combine:

70% Neo-Brutalism

20% Editorial / Swiss-inspired grid design

10% experimental digital interaction

Visual characteristics:

- thick black borders

- hard rectangular containers

- square or nearly-square corners

- zero or extremely minimal blur shadows

- hard offset shadows

- oversized typography

- strong grid

- visible structure

- asymmetrical compositions

- large whitespace areas

- bold colour blocks

- labels and metadata

- technical/editorial typography

- expressive hover states

- animated geometric elements

- moving lines

- scrolling marquees

- interactive cards

- pinned sections

- controlled visual chaos

Avoid:

- glassmorphism

- excessive gradients

- floating glass cards

- soft neumorphism

- excessive rounded cards

- generic 3D SaaS illustrations

- generic corporate stock photography

- excessive drop shadows

- conventional hero/three-column/service cards

- generic "We help brands grow" copy

- template-like sections

Neo-brutalism should feel intentional, premium and engineered, NOT amateur or visually broken.

28. PERFORMANCE

==================================================

The site must NOT become a heavy animation demo that scores poorly.

- responsive image sizes

- use modern image formats

- avoid unnecessary JavaScript

- avoid huge libraries unless required

- avoid blocking fonts

- avoid layout shifts

- respect prefers-reduced-motion

- animation should degrade gracefully

- mobile should have simplified animations

- no constant GPU-intensive animation

- avoid excessive blur

- avoid giant WebGL scenes unless absolutely necessary
