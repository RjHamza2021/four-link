# 4NDS Network Homepage

## Goal

Build the UK-facing homepage as a premium neo-brutalist digital network experience. It will communicate BUILD + DESIGN + BRAND + GROW as one connected system while preserving verified 4NDS identity and content.

## Homepage experience

- Add the ticker and compact sticky navigation with an animated mobile menu.

- Create an asymmetric oversized hero with a lightweight pointer-reactive network visual and strong project CTAs.

- Build interactive specialism panels, restrained marquees, editorial selected-work layouts, a scroll-led process, large statement reveals, industry wall, SEO audit interface, timeline, contact form, and giant footer.

- Use real 4NDS services and verified public project details only; label unavailable content honestly rather than fabricating evidence.

## Interaction and quality

- Implement physical button states, panel expansion, contextual desktop cursor, reveal/count animations, network motion, compact-on-scroll navigation, and an animated form confirmation.

- Simplify motion on mobile and fully respect reduced-motion preferences.

- Ensure semantic structure, keyboard operation, visible focus states, form labels, strong contrast, and no horizontal overflow.

## Technical details

- Keep the existing TanStack Start architecture and use React, TypeScript, Tailwind CSS, CSS/SVG, and small browser-native animation code instead of a heavy animation library.

- Define the full colour, typography, border, shadow, spacing, and motion system centrally using semantic tokens.

- Add unique homepage metadata and validate the running page at desktop and mobile sizes.

## Scope

This phase delivers the homepage only. Linked secondary pages and live SEO analysis remain for later phases; homepage controls will communicate unavailable destinations without fake results.
